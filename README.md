# Manual do Usuário: Pesquisa de Preços Lite

Este repositório contém a documentação técnica e o manual do usuário para a ferramenta **Pesquisa de Preços Lite** do portal Compras.gov.br.

## Estrutura do Projeto

A documentação foi desenvolvida utilizando [MkDocs](https://www.mkdocs.org/) com o tema **Read the Docs**.

- `docs/`: Contém os ficheiros de conteúdo em Markdown (`.md`), imagens e scripts customizados.
- `mkdocs.yml`: Ficheiro de configuração do MkDocs.
- `.readthedocs.yaml`: Ficheiro de configuração para publicação no Read the Docs.
